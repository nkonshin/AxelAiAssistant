# Axel v2 — быстрый старт (защита лаб)

## Запуск
Двойной клик по **«Ассистент защиты.command»** на рабочем столе (или `scripts/start_v2.sh`).
Откроется Терминал (его не закрывать) и окно «Заметки» на втором мониторе. Слушать начинает сразу.

## Один раз перед первой защитой (2 минуты)
1. **Разрешение на звук Zoom.** В окне ⚙ → «Проверить звук». Если «не слышен»:
   Настройки macOS → Конфиденциальность и безопасность → **Запись экрана и системного звука** →
   раздел «Только запись системного звука» → включить **Терминал** (или «+» и добавить его) →
   перезапустить ассистента. Повторить «Проверить звук» — должно быть «слышен».
2. **Динамик в звонке — системный по умолчанию**, говорить в наушниках (тогда микрофон не ловит преподавателя).
   Ассистент слышит весь звук Mac, поэтому программа звонка не важна:
   - **Zoom:** Настройки → Звук → Динамик: «Как в системе».
   - **Яндекс Телемост (браузер или приложение):** ⚙ в звонке → Динамики: «По умолчанию».
   - **Google Meet (браузер):** ⋮ → Настройки → Аудио → Динамики: «По умолчанию».
   Наушники переключил посреди звонка — ассистент сам перезапустит захват (покажет уведомление).
3. **Демонстрация — только один экран или одно окно**, не «Весь рабочий стол»:
   - Zoom: «Демонстрация экрана» → выбрать Экран 1 (или окно браузера/ноутбука);
   - Телемост / Meet в браузере: «Показать экран» → вкладка «Окно» (окно с ноутбуком) или «Весь экран» → нужный монитор.
   Окно ассистента держать на другом мониторе. Галочка «скрывать от записи экрана» на macOS 15+
   не гарантирует невидимость (Zoom её игнорирует).
4. Проверка связи: ⚙ → «Проверить модель» (ответ за ~1 с).

## Во время защиты
- Ответ появляется сам, когда преподаватель **задал вопрос или о чём-то попросил** и договорил (~1 с паузы). Рассуждения вслух без вопроса подсказку не создают — в разговоре будет пометка «без вопроса»; нужно ответить — ⌘⇧A. Режим меняется в ⚙ → «Автоответ».
- Подсказки идут **лентой**: каждый ответ — своя карточка, уже показанный ответ не перезаписывается. Жёлтая плашка «Скажи» — что произнести, ниже — детали.
- Преподаватель продолжил мысль после подсказки — ниже появляется короткое **«Дополнение»**, первая карточка остаётся.
- Пока ты говоришь (и 2,5 с после) или ответ на экране меньше 6 с — экран не уезжает: внизу кнопка «↓ Новый ответ». Договорил — лента сама перейдёт к новому; сразу — **⌘⇧J** или клик по кнопке. Прокрутил вверх к старому ответу — лента ждёт, пока не вернёшься.
- **⌘⇧A** — ответить сейчас (если не сработало само). **⌘⇧S** — скриншот экрана + подсказка.
- **⌃⇧1, ⌃⇧2** (Control+Shift+цифра) — работа: 1 Пингвины, 2 Млекопитающие (КТ2; КТ1 сдана и убрана из материалов). Или кнопками вверху окна. (⌘⇧3/4/5 заняты скриншотами macOS.)
- **⌘⇧M** — пауза, **⌘⇧\\** — скрыть окно, **⌘⇧D** — перенести окно на другой монитор, **⌘⇧X** — отменить ответ.
- Распознавание подвело — напиши вопрос внизу и Enter.

## Как устроено
Системный звук (Core Audio tap, утилита `audiotee`, без BlackHole) + микрофон → Deepgram Nova-3 (ru)
→ определение конца реплики → Claude Haiku через Claude Code (подписка; 2 тёплых процесса, контекст
в кэше, первый токен ~0,9 с) → окно. С ключом Anthropic (⚙) ответы идут через API, при сбое — через подписку.

Материалы: `~/Documents/PSU/4.1/Анализ данных/Ассистент/` (шпаргалки + ноутбуки КТ1 и КТ2, по папке на работу,
`_common.md` — общая теория и задания КТ). Журнал разговоров: `~/.axel-assistant/sessions/`. Логи: `~/.axel-assistant/v2.log`.

## Если что-то не так
| Симптом | Что делать |
|---|---|
| Плашка «Голос из Zoom не захватывается» / индикатор Zoom жёлтый | ⚙ → Проверить звук → разрешение для Терминала (п.1) → перезапуск |
| Индикатор Zoom зелёный, но текста нет | Посмотри «Распознавание» в верхней панели; ⚙ → «Перезапустить звук» |
| Сменил наушники/колонки во время звонка | ⚙ → «Перезапустить звук» |
| «Claude Code не готов» | В Терминале: `claude` → `/login`, потом перезапуск |
| Окно не открылось | Открой http://127.0.0.1:8765/ui в браузере (хоткеи там не работают, кнопки — да) |
